什么是集群？

集群将多台 DBSyncer 组成高可用部署，通过选主与任务租约协同工作。单节点故障时由其他节点接管，全量同步可按表分摊到多节点并行执行：

  • 高可用选主：自动选举 Leader，配置变更集中在主节点
  • 表级均摊：全量任务按表分配到在线节点，提升吞吐
  • 故障续跑：节点掉线后租约过期再改派，已完成表不重跑

适用于：生产多机部署、任务水平扩展、主备切换运维等场景。
