什么是集群？

简单说：把多台 DBSyncer 组成一套「永不掉线」的同步服务。一台出问题，其他机器立刻顶上；数据量大了，也能多机一起干——更快、更稳、更省心。

四大核心优势：

  • 高性能：大任务自动拆分，多机并行同步，速度成倍提升
  • 高稳定：任务智能分配、异常自动恢复，已做完的不重跑，过程少折腾
  • 高可用（HA）：某台机器挂了，其他机器立刻接手，保障同步业务不停、数据不断档
  • 动态扩容：业务量涨了直接加机器，能力跟着长，不用停服重启、无需额外配置

适合：高可用、更大规模的数据同步场景。比如同步多个库到数仓中心、满足TB级别以上数据迁移、增量同步性能超1w+TPS。
