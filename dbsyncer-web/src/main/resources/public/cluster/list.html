什么是集群？

简单说：将多台 DBSyncer 节点组成一套高可用同步服务。单台节点故障，其余节点自动接管任务；数据同步压力变大时，多节点共同分担负载，实现更快、更稳的同步能力。

四大核心优势：

  • 高性能：大任务自动拆分，多机并行同步，速度成倍提升
  • 高稳定：任务智能分配、异常自动恢复，已做完的不重跑，过程少折腾
  • 高可用（HA）：某台机器挂了，其他机器立刻接手，保障同步业务不停、数据不断档
  • 动态扩容：业务量涨了直接加机器，能力跟着长，不用停服重启、无需额外配置

适用场景：对同步连续性有要求、大规模数据同步场景。例如多业务库同步至数仓、TB 级数据迁移、增量同步吞吐 1w+ TPS 的业务。
